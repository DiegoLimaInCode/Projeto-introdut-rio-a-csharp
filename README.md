## 📋 Sobre o Projeto

Projeto desenvolvido como introdução à linguagem C#, explorando os conceitos fundamentais da programação orientada a objetos e as funcionalidades básicas da plataforma .NET.

## 🎯 Objetivos

- Aprender a sintaxe básica do C#
- Compreender os fundamentos da programação orientada a objetos
- Trabalhar com tipos de dados e estruturas de controle
- Desenvolver lógica de programação
- Familiarizar-se com o ambiente de desenvolvimento .NET

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C#
- **Framework:** .NET
- **IDE:** Visual Studio / Visual Studio Code

## 🚀 Como Executar

### Pré-requisitos

- [.NET SDK](https://dotnet.microsoft.com/download) instalado na máquina
- Visual Studio, Visual Studio Code ou qualquer editor de código de sua preferência

### Passos para execução

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/DiegoLimaInCode/Projeto-introdut-rio-a-csharp.git
   ```

2. **Navegue até o diretório do projeto:**
   ```bash
   cd Projeto-introdut-rio-a-csharp
   ```

3. **Execute o projeto:**
   ```bash
   dotnet run
   ```

## 💻 Compilação

Para compilar o projeto sem executá-lo:

```bash
dotnet build
```

Para criar um executável de publicação:

```bash
dotnet publish -c Release
```
